# Unit of Work — Story Map

**단계**: INCEPTION → Units Generation (Part 2)
**목적**: 33개 사용자 스토리를 6개 단위에 매핑(누락 0). 프론트/백엔드가 함께 필요한 스토리는 백엔드 단위(주 구현)와 프론트 단위(UI)에 모두 표기.

## 커버리지 검증
- **총 스토리**: 33 (AUTH 5 · MENU 7 · ORDER 12 · SESSION 4 · TENANT 5)
- **백엔드 배정**: U1(5) + U2(5) + U3(7) + U4(12) = 29 (장바구니 4건은 클라이언트 주 구현이나 주문 확정 경유로 U4와 연계)
- **프론트 배정**: U5·U6가 모든 사용자 대면 스토리의 UI 담당
- **미배정 스토리**: 0 ✅ — 모든 스토리가 최소 1개 백엔드 또는 프론트 단위에 매핑됨
