4. 성공 기준 (Success Criteria)

  • Primary Goal: 멀티테넌트 테이블오더 서비스를 로컬 docker-compose로 동작 가능하게 구현
  • Deliverables: FastAPI 백엔드 · React 고객/관리자 프론트 · 관계형 DB 스키마 · SSE 실시간 · docker-compose
  • Quality Gate — 스토리: 33개 사용자 스토리의 Gherkin 수용 기준 충족
  • Quality Gate — 보안: SECURITY-01~15 준수 (인증·격리·입력검증·헤더)
  • Quality Gate — PBT: Hypothesis 속성 테스트 — 총액/세션/격리 불변식 통과
  • Quality Gate — 복원력: 헬스체크·백업·그레이스풀 디그레이드·SSE 재연결
