1. 페르소나 (Personas)

🙋 고객 (Customer)

테이블에 착석해 태블릿으로 직접 주문하는 방문객

목표

  • 대기·호출 없이 즉시 원하는 메뉴를 주문
  • 주문 내역과 진행 상태를 스스로 확인

특성

  • 로그인/앱 설치 없이 바로 사용 (자동 로그인된 태블릿)
  • 터치 기반, 다양한 연령층

페인포인트

  • 직원 호출 대기, 복잡한 조작
  • 내 주문이 접수됐는지 불확실

🧑‍🍳 매장 관리자/운영자 (Admin)

매장을 설정·운영하고 주문을 실시간 관리하는 운영자

목표

  • 들어오는 주문을 실시간으로 놓치지 않고 처리
  • 테이블·메뉴·세션을 효율적으로 관리, 인건비 절감

특성

  • 매장 식별자 기반 인증(16h 세션)으로 관리 화면 접근
  • 다수 테이블을 한 화면(그리드)에서 모니터링

페인포인트

  • 신규 주문 인지 지연, 테이블별 현황 파악 어려움
  • 세션 종료/직권 수정 등 운영 처리의 번거로움

2. 사용자 여정 (User Journeys)

🙋 고객 여정
STEP 1
자동 로그인
태블릿이 저장된 정보로 매장·테이블 세션에 자동 진입
STEP 2
메뉴 탐색
기본 화면=메뉴, 카테고리별 카드 UI로 선택
STEP 3
장바구니
추가/수량조절, 총액 실시간, 로컬 저장
STEP 4
주문 확정
주문번호 표시 → 장바구니 비움 → 메뉴로 복귀
STEP 5
내역 확인
현재 세션 주문/상태를 실시간(SSE)으로 조회
🧑‍🍳 관리자 여정
STEP 1
매장 인증
매장 식별자+계정 로그인, JWT 16h 세션
STEP 2
실시간 모니터링
테이블 그리드에서 신규 주문 2초 내 표시(SSE)
STEP 3
주문 처리
상태 변경(대기→준비→완료), 직권 삭제
STEP 4
테이블/세션 관리
초기 설정, 이용 완료→이력 이동·총액 리셋
STEP 5
메뉴 관리
등록/수정/삭제/순서 조정, 과거 내역 조회

3. 사용자 대면 기능 (User-Facing Capabilities)

ID페르소나사용자가 할 수 있는 것연계 규칙
FR-C1고객별도 로그인 없이 태블릿 자동 로그인으로 즉시 주문 시작SEC
FR-C2고객카테고리별 메뉴 탐색 및 상세(가격·설명·이미지) 확인
FR-C3고객장바구니에 담고 수량 조절·총액 확인(새로고침에도 유지)PBT
FR-C4고객주문 확정 → 주문번호 확인 → 자동 리다이렉트SECPBT
FR-C5고객현재 세션의 주문·상태를 실시간으로 조회RT
FR-A1관리자매장 계정으로 안전하게 로그인(16h 세션 유지)SEC
FR-A2관리자테이블별 그리드에서 실시간 주문 모니터링·상태 변경RT
FR-A3관리자테이블 초기 설정, 주문 직권 삭제, 세션 종료(이력 이동), 과거 내역 조회PBTRES
FR-A4관리자메뉴 등록·수정·삭제·노출 순서 조정SEC
FR-MT1/2공통모든 데이터는 매장 단위로 격리, 타 매장/테이블 데이터 접근 불가SEC
SEC 보안 규칙 연계 · RES 복원력 규칙 연계 · PBT 속성 기반 테스트 대상 · RT 실시간(SSE)

4. 사용자 관점 범위 밖 (Out of Scope)

고객·관리자 모두 다음은 사용하지 않습니다: 실제 결제/영수증/포인트, SNS·2FA 로그인, 푸시·SMS·이메일 알림, 주방 전달/재고, 매출 분석·리포트, 예약·리뷰·다국어, 배달/POS/지도 연동. (메뉴 이미지는 URL 참조만, 업로드 없음)
